# Metta's Den Census Data
All the information found in the each Cutie Patootie Census Data file, converted to machine-readable JSON for data analysis and visuals. The format for the data can be found in [Census.d.ts](Census.d.ts). I'll try to keep this as up-to-date as I can, but I can't always guarantee I'll get to it quickly.

I am not affiliated with the Metta's Den Discord or Community Sever for The Isle, just a fan of the server and a data-lover.
